Why Orb

A calmer interface for
an active agent.

The terminal already has enough text. Orb adds just enough presence to tell you when it is listening, thinking, working, or waiting — then gets out of the way.

Speak naturally

Use voice while keeping your eyes on code, logs, or the task Pi is running. Orb renders a living braille-and-dots sphere in a compact panel above Pi — one glance tells you the state, and Pi's own screen stays untouched.

voice / live interaction

One glance is enough

The sphere changes character with the system state instead of filling another panel with indicators — a quiet presence when idle, crisp two-tone when talking, a calmer sweep while working, gray when muted.

state at a glance

You keep directing

Orb delegates whole tasks, cancels or redirects a wrong turn, switches model or thinking level, and comes back with outcomes — while your keyboard and Pi's output stay independent.

agent-aware / terminal-first
The orb, live

Watch it breathe.

This is the actual presence sphere from the Orb labs, running in your browser. Pick a state — it animates live.

Every state, one sphere

The same seeded-noise sphere drives presence, listening, thinking, and speaking — the only two things that change are what it's doing and how it's colored.

In the terminal this is rendered with your theme's accents, so it inherits the look of the Pi theme you already use.

The useful parts

Presence without a dashboard.

01
Live voice state
See when Orb is listening, speaking, or muted with a compact visual language that stays legible even in a dense terminal.
02
Agent activity
Keep track of whether Pi is idle or working without moving attention to a separate application.
03
Tool-aware feedback
Orb's tool and control actions sit alongside the voice layer, so speech and Pi's terminal output remain one continuous interaction.
04
Terminal character
Braille and character-cell rendering gives Orb a visual identity that belongs in the CLI instead of looking pasted on top of it — and it inherits your active Pi theme.
Install

Use it as a Pi package
or launch Pi through Orb.

Open source and MIT-licensed on GitHub. Install as a Pi extension, then open the voice panel inside Pi — or use the convenience launcher to start Pi with Orb attached.

setup · orbgithub.com/alainux/orb

As a Pi package

pi install https://github.com/alainux/orb
pi
/voice

macOS / Linux launcher

curl -fsSL https://raw.githubusercontent.com/alainux/orb/main/scripts/install.sh | sh
orb

Windows PowerShell

iwr https://raw.githubusercontent.com/alainux/orb/main/scripts/install.ps1 -UseBasicParsing | iex
orb
